## Filing Issues

Before filing an issue:
1. Search existing issues — your problem may already be reported
2. Check the runbooks — `docs/runbooks/` covers common production issues
3. Provide a minimal reproduction — include logs, configuration, steps

## Security Issues

Do **not** file GitHub issues for security vulnerabilities. Email `security@syncflow.dev` instead.
